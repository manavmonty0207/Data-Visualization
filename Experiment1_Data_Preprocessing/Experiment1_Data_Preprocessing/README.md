# Experiment 1 – Data Preprocessing and Visualization

## What is included?
- `main.py` – one reusable Python program for all three datasets.
- `datasets/` – three CSV files:
  - `housing_sample.csv`: illustrative housing data with mixed column types and deliberately added missing values, duplicates and extreme values for practice. It is NOT an official real-estate dataset.
  - `diabetes.csv`: scikit-learn diabetes sample dataset.
  - `wine.csv`: scikit-learn wine sample dataset.
- `outputs/` – output files and graphs generated by running the program.

## Step 1: Install Python packages
Open Command Prompt in this folder and run:

```bash
py -m pip install pandas numpy matplotlib scikit-learn
```

If `py` does not work, try `python -m pip install pandas numpy matplotlib scikit-learn`.

## Step 2: Run the program

```bash
py main.py
```

The program reads each CSV, fills missing values, removes duplicate rows, caps numeric outliers using the IQR method, applies Min-Max normalization and Z-score standardization, and saves plots.

## Step 3: Where are the outputs?
For each dataset, open its folder under `outputs/`:
- `cleaned_data.csv`
- `minmax_normalized.csv`
- `zscore_standardized.csv`
- `bar_plot.png`
- `box_plot_comparison.png`
- `histogram_comparison.png`
- `scatter_comparison.png`

## Important notes for explaining the experiment
1. Numeric missing values are filled with the column median.
2. Categorical missing values are filled with the most frequent value (mode).
3. Exact duplicate rows are removed.
4. Outliers are capped using the IQR limits. This keeps the rows rather than deleting them.
5. Min-Max formula: (x - minimum) / (maximum - minimum).
6. Z-score formula: (x - mean) / standard deviation.
7. Scaling is applied only to numeric columns. Text categories are not scaled.
8. The bar chart compares feature means; it is not a frequency chart of categories.
9. The housing CSV is a small illustrative dataset for learning the workflow. If your instructor requires a particular official housing dataset, replace it with the specified CSV and update the file name in `main.py`.
